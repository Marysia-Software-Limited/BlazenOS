# Komenda: `remember_note`

> Zapisuje notatkę (tekst + audio wypowiedzi, gdy klip jest świeży). Odczyt: „co wiesz o …”.

## Wyzwalacze (PL — runtime)

- „zapamiętaj[,] że <treść>”
- „zapamiętaj: <tytuł>. <treść>”

## Triggers (EN — asset, wyłączony w runtime)

- "remember that <text>"

## Parametry

- treść — notatka; opcjonalny tytuł przed kropką

*Źródło: drabinka silnika (`assistant/engine.py`, ścieżka nlu.miss).*
